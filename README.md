# Keyboard Display

A Minecraft mod that adds an on-screen keyboard overlay to your game, visually highlighting every key you press in real-time. This keyboard display mod is designed for players who want to see their inputs reflected on screen, whether for recording, streaming, or simply understanding their key usage during gameplay.

## Install

1. Download and install the **Fabric Loader** for Minecraft 1.21.4 from the official Fabric website.
2. Download **Fabric API** version 0.110.0+1.21.4 and place it in your `mods` folder.
3. Place the `keyboard-display-1.0.0.jar` file into the same `mods` folder.
4. Launch Minecraft 1.21.4 with the Fabric profile.

## Use

Once installed, the on-screen keyboard will appear automatically at the top-center of your screen. Here's how to interact with it:

1. **View your key presses**: As you play, any key you press or hold will be highlighted in bright green on the keyboard display.
2. **Toggle the display**: Press **K** (default keybinding) to show or hide the keyboard overlay.
3. **Customize the keybinding**: Go to *Options → Controls → Key Binds* and find the "Keyboard Display" category to change the toggle key to your preference.
4. **Monitor special keys**: The display tracks all standard keyboard keys including WASD, number keys, letters, arrow keys, modifier keys (Shift, Ctrl, Alt), Space, Enter, and function keys.
